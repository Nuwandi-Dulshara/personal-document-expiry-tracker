# Document Tracker Frontend Implementation Plan

**Goal:** Implement the supplied frontend specification in `frontend/document-expiry-tracker-ui`.
**Spec:** `personal-document-expiry-tracker-frontend-plan.md`
**Architecture:** Standalone Angular route components, shared presentation components, injectable domain services backed by a browser-local mock store. Reactive forms validate input; Angular Material provides accessible confirmation dialogs and notifications. Date-only comparisons use calendar days.
**Tech Stack:** Angular 21, TypeScript, SCSS, Angular Material, Router, Reactive Forms, HttpClient, Vitest.

## Constraints
- Yellow #F4B400, brown #5D4037 and #3E2723, neutral grey surfaces.
- Frontend only; no API, JWT, actual uploads, or delivered notifications.
- Existing backend/database folders are outside this change.
- Demo records persist locally; passwords are never persisted.

## Implementation checklist
- [x] Foundation: scaffold Angular, install Material, define theme, shared components, responsive navigation and header.
- [x] Data: typed user/document/category/reminder/summary/settings models, mock store, domain service boundaries, date boundary tests.
- [x] Authentication: validated login/register, mock session guard, logout, clear demo-only password recovery/change explanations.
- [x] Dashboard: derived counts, upcoming expirations, recent documents, four quick actions.
- [x] Documents: search name/number/issuer, status/category/expiry filters, pagination, responsive cards, add/view/edit/delete with confirmation, date validation and attachment metadata UI.
- [x] Supporting pages: category CRUD with duplicate/in-use protection, reminders and dismissal, editable profile, saved warning/reminder preferences, 404.
- [x] Verification: production build, unit tests for dates and state changes, responsive/browser checks when browser tooling is available, launch documentation.

## Verification cases
1. Yesterday is expired; today and warning boundary are expiring soon; boundary + 1 is active.
2. Adding/updating/deleting a document updates dashboard counts and reminders.
3. Required and inconsistent dates block submission; cancel preserves data.
4. Used categories cannot be deleted; renaming maintains document association.
5. Protected routes redirect anonymous visitors; mock login enables navigation.
6. Search/filter changes reset pagination; empty results show recovery action.
7. Layout has no horizontal overflow at 375/480/768/1024/1440/1920px.
